# 来源表结构标准化

把用户提供的来源表结构说明整理成统一字段列表。

## 适用场景

用户给出的是自然语言或松散说明，程序无法直接得到字段名、类型和描述。

## 步骤

1. 只提取用户明确写出的字段名称和说明。
2. 用户没有写出类型时，`field_type` 必须是 `unknown`。
3. 不要根据字段名称猜测 IP、时间或 URL 等类型。
4. 字段名称不能为空，字段标识不能重复。
5. 不要生成映射、提取规则或清洗规则。

## 输出

只输出一个 JSON 对象，包含 `source_fields`。每个元素包含 `field_id`、`field_name`、`field_type`、`description`。
