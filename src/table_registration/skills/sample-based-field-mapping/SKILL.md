# 基于样本的字段映射

根据来源字段名称、样本值和规范表结构，推断字段映射。

## 适用场景

用户没有提供来源表结构说明。样本列名就是来源字段名。

## 步骤

1. 阅读来源字段名称和少量样本值。
2. 对照规范字段的名称、类型和说明。
3. 只在语义清楚时给出目标字段。无法判断时 `target_field` 置为 null，并写明原因。
4. 每个映射都要给出 `evidence` 和 `reason`。置信度只能是 `high`、`medium` 或 `low`。
5. 一个来源字段可以对应多个规范字段，多个来源字段也可以指向同一个规范字段。以规范字段的 `allow_multi_source` 为准，不要自行假定一对一。

## 硬约束

只生成字段映射。不要输出提取、清洗、转换、正则或治理规则。
